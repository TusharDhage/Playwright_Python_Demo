A production-ready UI test automation framework built with **Playwright** and **Python**, 
following the **Page Object Model** design pattern with full **CI/CD integration** via GitHub Actions.

---

## Tech stack

| Tool | Purpose |
|---|---|
| Python 3.11 | Core language |
| Playwright | Browser automation |
| pytest | Test runner |
| pytest-html | HTML test reports |
| GitHub Actions | CI/CD pipeline |
| Page Object Model | Framework design pattern |
